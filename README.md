# ALIGN

## Hack your posture: wearable sensor and real-time posture feedback for desk warriors.

ALIGN is a posture monitoring system that uses an IMU sensor attached to a wearable harness to detect a user’s posture. The sensor sends data to an Arduino, which communicates with a Node.js server via serial connection. The server streams posture updates to a web-based frontend, which displays a simple interface indicating “Good” or “Bad” posture in real time, helping users maintain proper posture throughout the day.
